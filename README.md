# Gurman Mostar

Static website for Gurman, a catering and lunch-box kitchen in Mostar that delivers across Herzegovina.

## Preview locally

Open `index.html` in a browser, or from this folder run:

```bash
npx --yes serve .
```

## Free hosting on GitHub Pages

Repository: https://github.com/axiomizetc-stack/gurmanmostar

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. The site is published at https://axiomizetc-stack.github.io/gurmanmostar/

The phone number, Instagram and Facebook links are the public ones from the Gurman Mostar page.
